# Финансы: трекер расходов с ИИ

Мобильное PWA-приложение для учёта доходов и расходов. Ставится на телефон как обычное приложение,
работает без интернета, а ИИ помогает вводить траты и разбирать месяц.

**Стек:** React 19, TypeScript, Vite, Motion, Dexie (IndexedDB), vite-plugin-pwa (Workbox), Claude API, CSS Modules.

## Возможности

- **Быстрый ввод одной строкой:** «кофе 350», «такси 420 вчера», «+50000 зарплата», «зп 120к». Сумма, дата и категория
  распознаются прямо на устройстве.
- **Распознавание с ИИ ✨:** сложные фразы вроде «вчера заправился на 2500 и купил воды за 80» Claude разбирает на несколько операций.
- **Обзор месяца:** баланс, доходы, расходы, кольцевая диаграмма по категориям, расходы по дням со средним значением.
- **История:** поиск по описанию, категории и сумме, фильтр по типу, редактирование и удаление с отменой.
- **Бюджеты:** лимиты по категориям, шкалы с предупреждением на 80% и превышением выше 100%.
- **Аналитика:** среднее в день, прогноз на месяц, сравнение с прошлым месяцем, самая крупная трата.
- **Разбор от ИИ:** Claude получает только сводку по категориям, без списка операций, и возвращает наблюдения и советы.
- **PWA:** установка на главный экран, работа без сети, уведомление о новой версии.
- **Данные только на устройстве:** IndexedDB, резервная копия в JSON, экспорт в CSV для Excel, восстановление.
- Светлая и тёмная темы, 6 валют, учёт safe area на iPhone, поддержка настройки «уменьшить движение».

## Команды

```bash
npm install      # зависимости
npm run dev      # dev-сервер
npm run build    # проверка типов и сборка в dist/
npm run preview  # собранная версия с Service Worker
npm run lint     # линтер
npm run icons    # пересобрать PNG-иконки из public/favicon.svg
```

## ИИ

Для ИИ-функций нужен API-ключ Anthropic: **Настройки → ИИ-помощник**. Ключ хранится только на устройстве,
а запросы идут из браузера напрямую в API (модель `claude-opus-5-5`, структурированный JSON-ответ).
Без ключа приложение работает полностью, кроме кнопки ✨ и разбора месяца.

> ⚠️ Ключ в браузере подходит для личного использования. Для публичного сервиса запросы нужно проксировать через свой сервер.

## Структура

```
src/
├── app/AppContext.tsx     общий контекст: настройки, месяц, форма, уведомления, навигация
├── data/categories.ts     категории: эмодзи, цвет палитры, ключевые слова для распознавания
├── db/                    IndexedDB (Dexie): схема, операции, реактивные хуки
├── lib/
│   ├── parse.ts           локальный разбор быстрого ввода
│   ├── ai.ts              Claude: разбор фраз и анализ месяца (грузится лениво)
│   ├── stats.ts           итоги, категории, дни, прогноз
│   ├── money.ts, dates.ts форматирование сумм и дат
│   ├── demo.ts            демо-данные
│   └── download.ts        экспорт JSON и CSV
├── hooks/                 тема, установка PWA, блокировка прокрутки
├── components/
│   ├── charts/            DonutChart, DailyBars, BudgetMeter, StatTiles
│   ├── transactions/      QuickAdd, TransactionForm, TransactionList, TransactionItem
│   ├── layout/            TabBar, ScreenHeader
│   └── ui/                Sheet, Toast, Segmented, MonthSwitcher, Card, Button, Icon, EmptyState
└── screens/               Overview, History, Budgets, Insights, Settings
```

Суммы хранятся целыми числами в копейках, чтобы не было ошибок округления.
Цвета категорий закреплены за ними навсегда, а палитра проверена на различимость при дальтонизме.

## Деплой

`.github/workflows/deploy.yml` собирает приложение и публикует его на GitHub Pages при пуше в `main`.
Один раз включите **Settings → Pages → Source: GitHub Actions**.
